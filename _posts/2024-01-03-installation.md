Follow these steps to get a local copy of the repository up and running:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/shazzar00ni/portfolio.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd portfolio
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

For detailed usage instructions, deployment strategies, and configuration settings, refer to the documentation section.
